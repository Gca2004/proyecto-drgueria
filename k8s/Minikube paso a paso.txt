Primero abrir PowerShell y ir a la ruta de la carpeta del proyecto

proyecto-drgueria/

después poner estos comandos por orden

(verificar que Docker escritorio esta funcionando)

iniciar minikube

1)	minikube start --memory=4096 --cpus=4 --driver=Docker

verificar

2)	minikube status

activar los addons

3)	minikube addons enable ingress

4)	minikube addons enable metrics-server

construir las imágenes de Docker en minikube:

5)	minikube -p minikube docker-env | Invoke-Expression

6) pegar todo junto y esperar

docker build -t drgueria/ms-usuarios:latest    ./ms-usuarios
docker build -t drgueria/ms-productos:latest   ./ms-productos
docker build -t drgueria/ms-proveedores:latest ./ms-proveedores
docker build -t drgueria/ms-compras:latest     ./ms-compras
docker build -t drgueria/ms-pagos:latest       ./ms-pagos
docker build -t drgueria/ms-notificaciones:latest ./ms-notificaciones
docker build -t drgueria/ms-auditoria:latest   ./ms-auditoria
docker build -t drgueria/ms-reportes:latest    ./ms-reportes
docker build -t drgueria/api-gateway:latest    ./api-gateway
docker build -t drgueria/frontend:latest       ./front

verificamos las imágenes esten disponibles

7)	minikube image ls | findstr drgueria

Manifiestos por Orden:

desde la raíz de la carpeta /back


# Namespace primero (siempre)

		kubectl apply -f k8s/namespace.yaml


# Secret global

		kubectl apply -f k8s/global-secret.yaml


# MySQL (base de todo)

		kubectl apply -f k8s/mysql/
	

# Esperar a que MySQL esté listo antes de continuar

		kubectl wait --for=condition=ready pod -l app=mysql -n drgueria --timeout=120s


# Microservicios (el orden importa)


	kubectl apply -f k8s/ms-usuarios/

	kubectl apply -f k8s/ms-productos/

	kubectl apply -f k8s/ms-proveedores/

	kubectl apply -f k8s/ms-compras/

	kubectl apply -f k8s/ms-pagos/

	kubectl apply -f k8s/ms-notificaciones/

	kubectl apply -f k8s/ms-auditoria/

	kubectl apply -f k8s/ms-reportes/


# API Gateway y Frontend

	kubectl apply -f k8s/api-Gateway/

	kubectl apply -f k8s/frontend/


# Ingress (al final)
	
	kubectl apply -f k8s/ingress.yaml


Verificamos que todo este corriendo
	
	kubectl get pods -n drgueria

ahora abrimos 2 terminales:

en la primera ponemos :

		kubectl port-forward svc/frontend-svc 80:80 -n drgueria

en la segunda ponemos:

		kubectl port-forward svc/api-gateway-svc 4000:4000 -n drgueria




y entramos a esta dirección			http://localhost





	Para apagar

pausar las 2 terminales:
	
	ctrl + c

	minikube stop



para sustentar:




# 1. Levantar cluster

	minikube start

# 2. Verificar pods

	kubectl get pods -n drgueria

# 3. Port-forward (2 terminales)

	kubectl port-forward svc/frontend-svc 80:80 -n drgueria


	kubectl port-forward svc/api-gateway-svc 4000:4000 -n drgueria


# 4. Abrir navegador en

				http://localhost  (front)

				http://localhost:4000/health	(health del Gateway, para ver si el 								back esta funcionando)
