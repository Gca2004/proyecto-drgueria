╔══════════════════════════════════════════════════════╗
║         DRGUERIA — Instrucciones de despliegue       ║
╚══════════════════════════════════════════════════════╝

REQUISITOS PREVIOS:
  - Docker Desktop instalado y corriendo
  - Minikube instalado
  - kubectl instalado
  - Tener la carpeta del proyecto completa

══════════════════════════════════════════════
PASO 1 — Abrir PowerShell como Administrador
          e ir a la carpeta del proyecto
══════════════════════════════════════════════

  cd ruta\a\Proyecto-drgueria

══════════════════════════════════════════════
PASO 2 — Iniciar Minikube
══════════════════════════════════════════════

  minikube start

══════════════════════════════════════════════
PASO 3 — Crear el namespace (PRIMERO que todo)
══════════════════════════════════════════════

  kubectl create namespace drgueria

══════════════════════════════════════════════
PASO 4 — Aplicar todos los manifiestos
══════════════════════════════════════════════

  kubectl apply -f back/k8s/ -n drgueria

  (Kubernetes descarga automáticamente las imágenes
   desde Docker Hub: gustavocoque/...)

══════════════════════════════════════════════
PASO 5 — Esperar que todos los pods estén Running
══════════════════════════════════════════════

  kubectl get pods -n drgueria

  Ejecuta ese comando varias veces hasta que TODOS
  los pods digan 1/1 Running. Puede tardar 3-5 minutos
  la primera vez porque baja las imágenes de internet.

  Si algún pod dice ImagePullBackOff o ErrImagePull,
  espera 1 minuto y vuelve a verificar.

══════════════════════════════════════════════
PASO 6 — Cargar los datos iniciales (seed)
══════════════════════════════════════════════

  .\seed-completo.ps1

  Si PowerShell lo bloquea, ejecuta primero:
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

  Luego sí:
  .\seed-completo.ps1

══════════════════════════════════════════════
PASO 7 — Abrir DOS terminales PowerShell nuevas
══════════════════════════════════════════════

  Terminal 1:
    kubectl port-forward svc/frontend-svc 80:80 -n drgueria

  Terminal 2:
    kubectl port-forward svc/api-gateway-svc 4000:4000 -n drgueria

  (Dejar ambas terminales abiertas mientras se usa)

══════════════════════════════════════════════
PASO 8 — Abrir el navegador
══════════════════════════════════════════════

  Frontend:  http://localhost
  API Health: http://localhost:4000/health

  Credenciales:
    Admin:    admin@gmail.com   / admin
    Cliente:  cliente@gmail.com / password123

══════════════════════════════════════════════
PARA APAGAR
══════════════════════════════════════════════

  1. En cada terminal: Ctrl + C
  2. minikube stop

══════════════════════════════════════════════
PARA VOLVER A ENCENDER (próximas veces)
══════════════════════════════════════════════

  minikube start
  (los pods vuelven solos, no hay que hacer apply ni seed de nuevo)

  Luego abrir 2 terminales con los port-forward del Paso 7.

══════════════════════════════════════════════
PARA SUSTENTAR
══════════════════════════════════════════════

  # Ver todos los pods corriendo
  kubectl get pods -n drgueria

  # Ver servicios
  kubectl get svc -n drgueria

  # Ver logs de un microservicio (ejemplo)
  kubectl logs deployment/ms-usuarios -n drgueria

  # Ver el namespace
  kubectl get namespace drgueria

  # Frontend
  http://localhost

  # Health del API Gateway
  http://localhost:4000/health
